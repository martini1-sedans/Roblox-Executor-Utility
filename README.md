## FAQ

### What is XCutors?

XCutors is an all-in-one Windows desktop package that bundles multiple popular Roblox script executors (Volt, Synapse Z, Potassium, Wave) and a universal loader (xcutorsLoader) into a single convenient launcher.

### Is XCutors free to use?

Yes. XCutors itself is free and open-source. However, some included executors may have their own licensing or premium tiers managed separately by their original developers.

### What are the system requirements?

XCutors requires Windows 10 or Windows 11 (64-bit), at least 4 GB of RAM, and a stable internet connection for downloading executor components and script library updates.

### How do I update the executors inside XCutors?

The built-in auto-update system checks for new versions each time you launch XCutors. You can also manually trigger an update check from the Settings menu under the Updates tab.

### Can I use multiple executors at the same time?

XCutors allows you to install multiple executors side by side, but you should only attach one executor to the Roblox client at a time to avoid conflicts and ensure stable script execution.

### Where can I find scripts to run?

XCutors includes a built-in script hub with a curated collection of popular community scripts. You can also paste scripts from external sources directly into the integrated editor.

### Does XCutors work on macOS or Linux?

No. XCutors and the bundled executors are designed exclusively for Windows. macOS and Linux are not supported at this time.

### How do I report bugs or request new features?

Please open an Issue on this GitHub repository using the provided templates. Include as much detail as possible such as your OS version, executor name, and steps to reproduce the problem.

### Is it safe to use XCutors?

XCutors is open-source so you can inspect the code yourself. We recommend downloading only from this official repository and always keeping Windows Defender or your preferred anticomponent active.
